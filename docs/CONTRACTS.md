# Договор этапа 1: адреса и экраны

Формы запросов и ответов — в `lib/types.ts`. Все адреса, кроме отмеченных
«открыт», требуют cookie входа (проверяет `proxy.ts`); ответ без входа —
401 JSON для `/api/*` и редирект на `/login` для страниц.

## Экраны

| Адрес | Что на нём |
| --- | --- |
| `/login` | Пароль. Если `APP_PASSWORD` не задан — подсказка, где его задать |
| `/` | Библиотека: «Продолжить» (последняя книга и глава), книги с обложками, «следующая готова», кнопка «Добавить главу». При первом запуске без выбранной модели — переход в `/settings?first=1` |
| `/add` | Три вкладки: «Вставить текст», «Файл» (.mht/.html — разбор в браузере), «Ссылка» (сервер пробует открыть). Предпросмотр: название, слов, начало и конец, цена, выбор книги → «Перевести» |
| `/share` | Принимает «Поделиться»: ссылка → попытка сервера; текст → предпросмотр как в `/add`; файл → разбор |
| `/read/[id]` | Читалка (клиентский компонент). Карточка старта для непереведённой главы; перевод по абзацам с опросом; темы, шрифт, интервал; нажатие на абзац — оригинал; подсветка терминов и карточка; «Дальше» с состоянием; «не гасить экран»; место чтения; «Что-то не так» |
| `/book/[id]` | Оглавление, «Готовый перевод» (глав, пары для сверки, «Собрать глоссарий — ≈ X ₽», ход сбора, «Остановить», «Убрать»), настройки книги (стиль, рассказчик, обращения), расход по книге |
| `/book/[id]/glossary` | Термины по разделам (пометка «из готового перевода»), правка ru/рода/имён, «кто кому ты/вы», свёрнутый список имён готового перевода, ещё не встретившихся по-английски |
| `/settings` | Модель перевода (с ценами, при первом запуске — обязательный выбор), модель поиска имён, усердие, месячный лимит, курс, «переводить сразу без карточки» |
| `/spend` | Расходы: месяц, лимит, по книгам, последние вызовы |
| `/status` | Проверки: база, ключ Anthropic, лимит, зависшие задачи, версия |
| `/button` | «Кнопка для сайтов»: выпустить ключ, «Установить», инструкции для Kiwi/Edge/Firefox и Chrome на ПК, самопроверка |

## Кнопка на сайтах и мост

Скрипт (`userscript/main.ts`) получает при отдаче `APP_ORIGIN` и `IMPORT_TOKEN`.

- На страницах сайтов: плавающая кнопка «Толмач», если страница похожа на
  главу. Сайты-приложения (Next.js и т. п.) листают главы без перезагрузки,
  а менеджер запускает скрипт один раз на документ, поэтому скрипт сам
  следит за адресом (раз в секунду, по `popstate` и `hashchange`; маршрут в
  якоре `#/…` считается адресом) и 15 с после загрузки или смены адреса — за
  дорисовкой страницы. Первые 0,5 с после смены адреса страницу не оценивает:
  по «Назад» сайт перерисовывается не сразу. Ушли на не-главу — кнопка уходит,
  когда 15 с прошли, а глава не появилась (медленная глава не заставит её
  мигать; посреди отправки ждём её конца). «Закрыть» действует до смены
  адреса и посреди отправки не предлагается; выкинутую сайтом кнопку
  возвращает. Запасной путь — пункт меню дополнения «Показать кнопку «Т»»
  (`GM_registerMenuCommand`): такую кнопку сам скрипт не убирает. Проверка —
  `tests/e2e/userscript-spa.mjs`.
  На русской странице (кириллицы больше латиницы) меню другое — готовый
  перевод: «Чей это перевод? Выбрать книгу» (список — `GET /api/reference/books`,
  выбор запоминается для книги на сайте — по `bookKeyFromUrl`, иначе для
  сайта), «Готовый перевод: взять эту главу / эту и следующие 10 / 50 / все».
  Обход идёт в этой же вкладке: дождаться текста главы (два замера подряд с
  тем же числом абзацев и не прошлая глава, до 20 с), отправить в
  `POST /api/reference/import` (с `expectedNumber` и `prevUrl`), пауза 3–5 с,
  переход по ссылке «Дальше» (`location.assign`) или нажатие кнопки «Далее»
  без адреса (продолжение в том же документе). Страница без текста
  (иллюстрации) — пройти мимо по «Дальше», до 3 подряд. Состояние
  `tolmach:walk` общее для вкладок, а id обхода — в `sessionStorage`: сам
  продолжает только вкладка, которая перешла, и только в течение 2 минут
  после перехода; другой вкладке меню предлагает «Продолжить обход» (если
  пульс обхода не свежий). «Остановить» стирает состояние. 409 от сервера
  (под номером уже глава с другого адреса) останавливает обход с причиной.
  Проверка — `tests/e2e/userscript-walk.mjs`.
  Меню на остальных страницах: «Перевести эту», «Взять эту и следующие 3 / 5 / 10». Отправка
  `POST {APP_ORIGIN}/api/import` с Bearer-ключом через `GM_xmlhttpRequest`,
  затем открыть `{APP_ORIGIN}/read/<chapterId>`.
- На страницах приложения (`location.origin === APP_ORIGIN`) — мост для
  «Дальше»: `window.postMessage({type:"tolmach:bridge-ready", version})` при
  загрузке; на `{type:"tolmach:fetch", requestId, url}` — `GM_xmlhttpRequest`
  GET страницы с куками пользователя → `DOMParser` → `markHiddenByStyles` →
  `extractFromDocument` → ответ `{type:"tolmach:fetched", requestId, ok, chapter?, code?}`.
  Импорт делает сама страница (у неё есть cookie).
