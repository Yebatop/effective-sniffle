# Установка «Толмача»

Всё делается в браузере, можно с телефона. Займёт 15–20 минут. Терминал не
нужен. Если на каком-то шаге видишь не то, что написано, — сделай снимок
экрана и пришли в чат.

## Шаг 1. Деньги и ключ Anthropic (5 минут)

1. Открой **platform.claude.com** и войди.
2. **Billing** → пополни баланс на **$5** (этого хватит примерно на 60 глав
   хорошей моделью; дешёвой — в несколько раз больше). **Автопополнение не включай** — тогда больше, чем
   положил, не спишут никогда.
3. **API keys** → **Create Key** → имя «Толмач» → **Create**. Скопируй ключ
   (начинается с `sk-ant-`). Он показывается один раз. Сохрани его у себя
   в заметках.

> Ключ — как пароль от кошелька. Вставляй его только в Vercel (шаг 3),
> никогда в чат и никуда больше.

По желанию — страховка: **Settings → Workspaces → Create workspace**
«Толмач» с месячным лимитом в долларах, и ключ создай внутри него.

## Шаг 2. Принять код в основную ветку (1 минута)

Код лежит в запросе на слияние (PR) на GitHub. Vercel выкладывает основную
ветку `main`, поэтому код надо в неё принять.

Проще всего — написать мне в чат «сливай», и я сделаю это сам. Или
вручную: github.com → репозиторий **effective-sniffle** → **Pull requests**
→ PR «План личного переводчика…» → **Ready for review** → **Merge pull
request** → **Confirm merge**.

## Шаг 3. Vercel — сам сайт (5 минут)

1. Открой **vercel.com** → **Sign Up** / **Log In** → **Continue with GitHub**.
   Тариф — **Hobby** (бесплатный).
2. **Add New…** → **Project** → в списке репозиториев найди
   **effective-sniffle** → **Import**. Если его нет в списке — **Adjust GitHub
   App Permissions** и разреши Vercel доступ к этому репозиторию.
3. На экране настройки проекта ничего не меняй, кроме **Environment
   Variables** — добавь две строки:

   | Key | Value |
   | --- | --- |
   | `ANTHROPIC_API_KEY` | ключ из шага 1 |
   | `APP_PASSWORD` | пароль для входа в Толмач — придумай любой, можно русскими буквами |

4. **Deploy**. Через минуту-две будет «Congratulations». Сайт уже
   открывается, но пока без базы — это следующий шаг.

## Шаг 4. База, где лежат книги (3 минуты)

1. В проекте на Vercel открой вкладку **Storage** → **Create Database**
   (или **Connect Store**) → выбери **Neon** → **Continue**.
2. Регион — **US East (N. Virginia)** / `us-east-1`: рядом с серверами
   Vercel, так быстрее. План — **Free**. **Create** / **Continue**.
3. Подключи базу к проекту — все окружения (Production, Preview,
   Development) → **Connect**.
4. Новые настройки доходят только до новой выкладки: вкладка **Deployments**
   → у верхней записи **⋯** → **Redeploy** → **Redeploy**.

## Шаг 5. Открыть Толмач на телефоне (2 минуты)

1. В проекте на Vercel, вкладка **Overview** → **Domains**: адрес вида
   `effective-sniffle-….vercel.app`. Открой его на телефоне в **Firefox** —
   в нём же потом будет кнопка «Т» (шаг 6). В Kiwi Толмач тоже открывается,
   но кнопка для сайтов там, скорее всего, не заработает.
   > Если просит войти в Vercel — открыт временный адрес выкладки, а не
   > основной. Возьми адрес из **Domains**.
2. Введи пароль из шага 3.
3. Выбери модель перевода — цены видны прямо на карточках.
4. **Настройки → Проверка**: все пункты должны быть с галочкой.
5. Поставь значок на главный экран: меню браузера **⋮** → **Добавить на
   главный экран** (или **Установить**). Тогда в меню «Поделиться» может
   появиться «Толмач».

## Шаг 6. Кнопка «Т» на сайтах (5–10 минут)

В Толмаче: **Настройки → Кнопка для сайтов**. Там пошаговая инструкция для
Kiwi, Edge, Firefox и компьютера и самопроверка «кнопка работает».

Коротко для Firefox на телефоне: меню **⋮** → **Расширения** → найти
**Violentmonkey** → **+** → **Добавить** → вернуться в Толмач → **Выпустить
ключ и установить** → **Установить кнопку** → **Установить** в окне
дополнения.

В Kiwi кнопка, скорее всего, не заработает: Violentmonkey и Tampermonkey из
магазина Chrome теперь в новой версии, которую Kiwi не запускает.

Кнопка появляется справа внизу на странице главы. Не появилась — потяни
страницу вниз, чтобы она перезагрузилась; если и так нет — меню дополнения →
**Показать кнопку «Т»**.

## Если что-то не так

- **Проверка** показывает, что сломано, и что с этим делать.
- В читалке есть **«Что-то не так»** — она даёт ссылку на отчёт. Пришли
  ссылку в чат: я разберу сам, без скриншотов и переписки.
- Новая версия выкладывается сама после каждой сессии. Если открыта старая,
  наверху появится «Есть новая версия — обновить».
